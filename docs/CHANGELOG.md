This update mainly reorganizes the code package structure to make future maintenance and updates easier.
If you are an addon developer or modpack author and have made code-level changes to this mod, you will need to adjust them once according to the new package structure. The mod’s main API has not changed; only the package paths have been updated, so this should be relatively easy to handle.

If you have only modified the mod’s recipes or made other datapack-level changes, no changes are required.

For players, this update should have no impact.
